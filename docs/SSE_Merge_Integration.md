## 接口与页面行为

新增 `POST /api/chat/stream`，请求字段与同步聊天接口相同。返回 `text/event-stream`，事件包括：

| 事件 | 含义 |
| --- | --- |
| `status` | 准备、检索和整理状态 |
| `meta` | 会话编号及解析后的商品身份 |
| `delta` | 可展示的模型回答初稿增量 |
| `done` | 校验后的最终回答、引用、会话和商品身份 |
| `error` | 超时、模型限流或其他执行失败，不能作为完成结果 |

前端在同一个回答气泡内追加正文增量，并用 `done` 的回答和引用替换初稿。断线保留已收到的内容并标记中断，不自动重发。缓存命中、范围拒绝、工具失败、空资料及程序直接整理业务字段等分支可能没有 `delta`，仍通过 `done` 返回完整结果。

队列最多64项，15秒无事件时发送心跳，总时限300秒。同一会话的请求在单进程内串行执行；这不提供多进程或跨实例的分布式锁。断线后工作线程继续完成当前轮并保存状态，停止向已断开的队列写入。

## 与第九周防护的兼容修复

新增回归实际复现了合并后的缺口：最终回答已经被内部模板输出检查拒绝，但原始流式初稿仍将模板发给前端。

`PromptSafeStream` 复用原有模板长句规则及全半角、空白、零宽字符和大小写归一化。在发送增量前，暂存与受保护模板开头相同的尾部：后续字符构成模板长句时停止正文发送；与模板不同的正常商品内容继续流式发送。最终回答通过检查后才释放剩余尾部。最终被拒绝的输出不附引用、不写共享答案缓存。

这与原有防护范围一致：匹配归一化后至少28字符的完整模板行，不把任意改写、编码或其他攻击都视为已覆盖。初稿仍可能在引用修复前显示未核验的引用编号，最终以 `done` 为准。

补充回归覆盖：初稿及引用修复输出内部模板、不同分块大小及字符混淆、正常相似前缀恢复发送、入口范围与注入拒绝、工具故障和空检索。
