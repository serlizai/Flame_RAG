# 第六周补齐与验收结果

验收日期：2026年10月29日。

## 补齐内容

1. **工具覆盖**：颜色、报价、售后问题使用各自专用工具。模型漏调时由后端补齐；混合问题实际执行商品信息、价格、售后三个工具，不用报价中的颜色字段替代商品信息查询。
2. **业务引用**：简单业务查询从本轮真实工具字段生成回答。颜色数量、配置、SKU、人民币分及引用编号均来自返回数据；售后保留适用条件。字段错误、商品不一致或本轮缺少可靠记录时不沿用旧值。
3. **卖点引用兜底**：生成回答漏引用时，只在本轮检索存在当前商品的核心卖点章节时，展示该章节原文及对应引用。不会把无依据的生成句附上来源。
4. **缓存规则**：提示词版本升级为 `product_prompt_v4`，避免旧回答绕过新规则。价格等业务回答继续不写共享答案缓存。

主要实现位于 `backend/business_answers.py`、`backend/nodes.py`、`backend/grounding.py` 和 `prompts.py`。Vue 与正式 API 的请求和响应字段保持兼容。

## 六个核心场景

| 场景 | 实际使用工具 | 核对结果 |
| --- | --- | --- |
| 商品卖点 | 商品知识检索 | 使用当前商品资料并带有效引用 |
| 商品颜色 | 商品信息 | X500 Pro 演示颜色为月光银，共1种，带对应引用 |
| 指定配置报价 | 价格 | 16GB 加512GB演示价格3999元，配置、金额与引用一致 |
| 七天退货 | 售后 | 保留未激活、未使用、包装配件齐全和订单凭证等条件 |
| 颜色加价格加退货 | 商品信息、价格、售后 | 三个工具均真实执行，各部分对应自己的依据 |
| 不存在的规格 | 价格 | 12GB 加512GB明确未查到，不使用其他配置报价，也不附无关引用 |

以上均通过。额外验证了未预选商品时按完整名称查询 Flame K1 电热水壶价格。

## 复现与证据

在项目根目录运行：

```text
uv run --no-sync python -m scripts.check_agent_acceptance --suite all --report .cache/week6-acceptance.json
```

真实 API 和原有工具测试需设置 `RUN_AGENT_INTEGRATION=1` 后执行：

```text
uv run --no-sync python -m pytest tests/test_business_agent.py tests/test_conversation_live.py -q -s
```

本次独立验收记录位于 `.cache/week6-final-acceptance.json`，最终真实测试记录位于 `.cache/week6-verified-api.xml`。测试使用独立会话并清理自身数据，不留下额外后台服务。

这些结果覆盖当前演示数据和列出的场景，不代表任意问题均能正确回答，也不代表真实商品参数、报价或售后承诺。正在运行的后端需重启后加载本次修改。
